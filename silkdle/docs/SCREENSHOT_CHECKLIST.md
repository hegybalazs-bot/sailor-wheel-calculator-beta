# Screenshot approval checklist

- [ ] Original Silkroad gameplay screenshot, not a generated illustration
- [ ] Single answer clearly corresponds to the visible target
- [ ] Category and Chinese / European / Mixed world correctly tagged
- [ ] Precise weapon degree or armor slot/degree checked when relevant
- [ ] Filename, source/creator, date and permission basis recorded
- [ ] No player identity, private messages or spoilers in the shared capture
- [ ] Main subject visible at medium and wide zoom
- [ ] At least one distinguishing detail appears before 100% reveal
- [ ] Correct spelling and aliases manually tested
- [ ] Screenshot loaded and previewed through admin UI
- [ ] Approval uses a substantive rights note, not a checkbox alone
- [ ] Approved image appears in the live practice pool
- [ ] Incorrect/revoked images are no longer public
